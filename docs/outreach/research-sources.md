# Research we cite, and the rule for citing it

An accessibility vendor that publishes a wrong number loses the only thing it is
selling. So: **no statistic goes into a post unless it has been read at its own source
in this file.** Not a search summary, not a secondary blog, not memory.

That rule already caught one. A search result attributed a 2026 lawsuit projection of
6,176 to UsableNet. The UsableNet article does not contain that figure. It was dropped.

---

## WebAIM Million 2026
`https://webaim.org/projects/million/` — verified at source 2026-09-07

| Figure | Value |
|---|---|
| Home pages with detected WCAG 2 failures | **95.9%** (up from 94.8% in 2025) |
| First year-over-year increase | after six consecutive years of small improvement |
| Distinct errors detected | 56,114,377 across 1,000,000 pages |
| Average errors per page | 56.1 |
| Six most common error types as a share of all errors | **96%** |
| Low contrast text | 83.9% of pages (from 79.1%), avg 34 instances per page |
| Missing alternative text | 53.1% |
| Missing form input labels | 51% |
| Empty links | 46.3% |
| Empty buttons | 30.6% |
| Missing document language | 13.5% |

WebAIM's own explanation for the reversal: rising page complexity and ARIA use,
attributed in part to third-party frameworks and AI-assisted coding.

**Why this is our best source.** Not because it proves the web is inaccessible — everyone
says that. Because six mechanical checks account for 96% of what is wrong, and two of
those six are exactly what we check on Confluence content. The argument writes itself and
it is not ours, which is what makes it persuasive.

## Digital accessibility litigation, 2025
`https://blog.usablenet.com/ada-web-lawsuit-trends-2026` — verified at source 2026-09-07

- **More than 5,000** digital accessibility lawsuits filed by the end of 2025.
- Federal filings: **3,100+**. New York and California state courts: **nearly 2,000**.

Use sparingly and always attributed. Litigation counts vary by who is counting and what
they include, and a vendor leaning on them reads as scaremongering. The honest framing is
that the number is evidence the obligation is enforced by people, not a prediction about
any particular reader.

## Not yet verified, do not cite
- Any 2026 lawsuit projection.
- Any figure about the cost of retrofitting versus building in accessibility.
- Anything about Confluence-specific accessibility rates. No such study exists; if we
  want that number, we will have to produce it ourselves.
