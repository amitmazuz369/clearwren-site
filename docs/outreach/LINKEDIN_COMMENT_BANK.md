## If They Mention Specific Problem

### "Missing alt text / image descriptions"
```
Exactly. We found 1,765 images without alt text across 311 pages — 
it's the most common failure. One paragraph per image solves it but 
most teams don't know where to start. Worth automating this check.
```

### "Broken heading hierarchy"
```
This is huge. 67% of sites get heading order wrong. H1 jumps to H3, 
H2 appears later — screen reader users lose the outline. Simple fix 
but needs to be in QA process.
```

### "Low contrast / readability"
```
We found 83% of sites have contrast issues, especially in dark mode. 
Most teams don't test both modes. A ratio checker fixes this in seconds.
```

### "Generic link text"
```
71% of sites have "click here" links. Screen reader users navigate by 
jumping links — they need descriptive text. Simple but massive impact.
```

### "No alt text / accessibility in general"
```
This is the #1 issue we see. We audited 1,179 pages across 13 sites 
and 57% had accessibility gaps. Usually manageable if you prioritize it.
```
