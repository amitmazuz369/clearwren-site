A sample conformance report

This is the report Clarable publishes in Confluence when you scan a space, run on a small demo space on 15 October 2026. The space is fictional: a nine-page staff handbook with some everyday problems written in on purpose, and some clean pages.

Produced by the same engine as the app (version 1.0.0), with the same layout and wording as the page the app writes into your space. The detail at the end is what the app's CSV export contains. Nothing here describes a real organisation.

Method

Each page body was parsed and evaluated against deterministic rules mapped to WCAG 2.2 success criteria. Automated checking cannot confirm every criterion; items marked for review need a person to confirm them.

"No failures found by automated checks" means exactly that. It is not a claim that the criterion is met: only a person can confirm that, and this report is not an Accessibility Conformance Report (VPAT).

Every finding, page by page

In the app this list comes as a CSV export, with the location of each finding.

Welcome to the team · score 66

  • critical Image has no alternative text — “media https://clearwren.com/assets/social/ig-…”
    1.1.1 (A). Select the image, open the image toolbar and add alt text that conveys the same information as the picture. If it is purely decorative, mark it as decorative so it is skipped.
  • moderate Heading level is skipped (for review) — “Accounts and tools”
    1.3.1 (A). Step heading levels down one at a time — an H2 section contains H3 subsections, not H4.
  • serious Bold text used instead of a heading (for review) — “Your first week”
    1.3.1 (A). Select the line and apply a real heading level from the text-style menu.
  • serious Link text does not say where it goes (for review) — “click here”
    2.4.4 (A). Rewrite the link text to name the destination, for example "2026 onboarding checklist" instead of "click here".

Benefits overview · score 91

  • advisory Bare URL used as link text (for review) — “https://example.com/benefits/pension-scheme-rules-2026.pdf”
    2.4.4 (A). Replace the URL with a short phrase describing the page it opens.
  • serious Table has no header row — “ContributionEmployeeEmployer”
    1.3.1 (A). Select the first row and turn on "Header row" in the table toolbar.

Travel and expenses · score 79

  • moderate Heading level is skipped (for review) — “Hotels”
    1.3.1 (A). Step heading levels down one at a time — an H2 section contains H3 subsections, not H4.
  • critical Text contrast is below the WCAG AA minimum — “Last reviewed by the finance team. Rates change every April.”
    1.4.3 (AA). Pick a darker text colour or a lighter background until the pair reaches 4.5:1 (3:1 for large headings).
  • moderate Instructions rely on colour alone (for review) — “Fill in the claim form. Fields in red are required, and claims withou…”
    1.4.1 (A). Add a second cue alongside the colour — a label, an icon, or bold text — and refer to that instead.

Meeting notes · score 93

  • moderate Dashes or numbers used instead of a list (for review) — “1) Welcome and introductions”
    1.3.1 (A). Select the lines and apply a bulleted or numbered list.
  • moderate Page title does not describe the page (for review) — “Meeting notes”
    2.4.2 (A). Rename the page to something that identifies its topic without the surrounding context.
  • advisory Long run of capital letters (for review) — “THE OFFICE MOVE IS CONFIRMED FOR THE FIRST WEEK OF MARCH”
    best practice. Use sentence case and apply bold or a heading if you need the text to stand out.

Office locations · score 92

  • serious Alternative text does not describe the image — “IMG_2041.jpg”
    1.1.1 (A). Replace the alt text with a sentence describing the information the image conveys in this context.

Onboarding checklist · score 97

  • moderate Same link text points to different pages (for review) — “guide”
    2.4.4 (A), 2.4.9 (AAA). Make each link text unique, for example "security guidelines" and "brand guidelines".
