3.1.2 Language of Parts (level AA)

Passages in a different language need to be marked as such.

How it shows up in Confluence

Confluence sets one language for the page, so a Hebrew paragraph inside an English page is announced by a screen reader using English pronunciation rules, which renders it unintelligible. Multilingual documentation sites hit this constantly.

What to do about it

Put substantial content in another language on its own page in that language, rather than mixing scripts within one page. Where a mixed page is unavoidable, say in the text which language the passage is in so a reader can switch tools.

What Clearwren checks for this criterion

  • Passage in a different script — A screen reader keeps using the page language, so text in another script is read with the wrong pronunciation rules.
